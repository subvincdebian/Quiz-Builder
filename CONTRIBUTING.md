# Contributing to Quiz Builder

Thank you for your interest in contributing to the Quiz Builder project!

## Development Workflow

1.  **Branching**: Please use conventional branch naming:
    - `feat/feature-name`
    - `fix/bug-name`
2.  **Commits**: Follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).
3.  **Architecture**: Strict adherence to Feature-Sliced Design (FSD) for frontend and Modular NestJS for backend.
4.  **Code Quality**:
    - Run `npm run lint` before committing.
    - Ensure all new features have appropriate type safety (TypeScript).
