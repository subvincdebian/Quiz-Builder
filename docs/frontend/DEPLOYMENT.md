# Deployment Guide

This document outlines the deployment strategy for the Quiz Builder frontend.

## Overview

The frontend is a static SPA generated by Vite.

## Build Process

1. Run `npm run build` in the `frontend` directory.
2. This generates a production-ready bundle in the `frontend/dist` directory.

## Deployment Strategy

The resulting `dist` folder can be served by any static file server (e.g., Nginx, Apache, or cloud storage like AWS S3 with CloudFront).

### Environment Configuration

Ensure the following environment variables are correctly set in the production environment:

- `VITE_API_URL`: The production URL of the backend API.
